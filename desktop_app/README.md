# BrandConnect 링크 생성기 - 데스크탑 앱

`BrandConnectLinkGenerator.app`을 더블클릭하면 실행되는 데스크탑 앱입니다.
크롬 확장 '네이버 브랜드 커넥터 쇼핑 검색'처럼 클릭 한 번으로 열리고, 여기서 한 발
더 나아가 **어떤 키워드를 검색할지 자동으로 찾아주고, 여러 키워드를 한 번에
처리**해줍니다.

## 처음 실행할 때 (macOS 보안 경고 우회)

macOS는 서명되지 않은 앱을 처음 열 때 "확인되지 않은 개발자" 경고를 띄웁니다.

1. `BrandConnectLinkGenerator.app`을 **더블클릭이 아니라 우클릭(Control-클릭)**
2. **"열기"** 선택
3. 경고 창에서 다시 **"열기"** 클릭 (최초 1회만 하면 됩니다)

## 화면 구성

앱을 열면 아래 3개 버튼이 있는 창이 뜹니다.

| 버튼 | 하는 일 |
|---|---|
| 1) 트렌드 분석 + 검증 실행 | `daily_food_data`를 분석하고 데이터랩 API로 검증해서 `keywords_for_brandconnect.txt`를 만듭니다 |
| 2) 브랜드커넥트 로그인 창 열기 | 실제 네이버 로그인 페이지를 브라우저 창으로 엽니다. 로그인/캡차는 그 창에서 직접 처리하세요. 한 번 로그인하면 세션이 저장되어 다음부터는 다시 로그인할 필요가 없습니다 |
| 3) 키워드로 링크 자동 생성 | 1번에서 만든 키워드 목록으로 브랜드커넥트 상품을 자동 검색해 제휴 링크를 생성합니다. (캡차/화면 인식 실패 시 직접 개입이 필요할 수 있어 새 터미널 창에서 실행됩니다) |

**추천 순서**: 1 → 2 (최초 1회만) → 3

## 로그인에 대한 중요 안내

캡차나 2단계 인증은 자동화 도구가 대신 처리할 수 없습니다(정책상 금지되어 있고,
네이버도 이를 감지해 차단합니다). 2번 버튼은 **실제 로그인 페이지를 열어드리는
것**까지만 하고, 로그인 자체는 항상 사용자가 직접 해야 합니다. 로그인 세션은
`brandconnect_link_tool/naver_browser_profile` 폴더에 저장되어 앱을 다시 열어도
유지됩니다.

## 문제가 생기면

- 앱이 아예 안 열리면: `desktop_app/last_run.log` 파일에 오류 로그가 남습니다.
- 3번 버튼으로 연 터미널 창에서 안내 문구가 뜨면 그 창에서 직접 진행해주세요
  (예: "브라우저 창에서 직접 클릭해주세요" 등).
- Chromium 최초 설치는 몇 분 걸릴 수 있습니다 (인터넷 필요).

## 폴더 구성

```
desktop_app/
  BrandConnectLinkGenerator.app/   ← 더블클릭해서 실행하는 앱
  gui_app.py                       ← 앱의 실제 GUI 코드
  open_brandconnect_login.py       ← '로그인 창 열기' 버튼이 실행하는 스크립트
  last_run.log                     ← 실행 로그 (문제 생기면 확인)
```
