인증 방식
✅ 방법 A: 쿠키 세션 (추천)
1. 최초 1회: 사용자가 직접 브라우저 로그인
2. 세션 쿠키를 ~/.naver_session.json에 저장
3. 이후 MCP가 저장된 쿠키로 자동 인증
4. 쿠키 만료 시 재로그인 안내
방법 B: 환경변수 자격증명
.env에 ID/PW 저장 → 매번 자동 로그인.
편리하지만 CAPTCHA/보안 인증에 걸릴 수 있음.
네이버의 비정상 로그인 감지 가능성 있음.
→ 방법 A가 더 안정적
⚠️ 주의: 네이버 공식 블로그 작성 API가 없으므로 이 MCP는 브라우저 UI를 자동화합니다. 네이버가 에디터 구조를 변경하면 일부 기능이 깨질 수 있습니다. 이미지 첨부는 로컬 파일 경로 기반으로 동작합니다.
MCP가 제공할 도구 (Tool) 목록
write_post()
새 글 작성 및 발행. 제목·본문·태그·카테고리·발행 여부(임시저장/발행) 설정 가능.
title, content, tags[], category, publish=True
get_posts()
블로그의 최근 글 목록 조회. 제목, URL, 작성일, 조회수 반환.
limit=10, page=1
edit_post()
기존 글 수정. post_id로 특정 글을 찾아 내용 업데이트.
post_id, title?, content?, tags?
upload_image()
로컬 이미지 파일을 블로그에 업로드하고 본문 삽입 가능한 URL 반환.
image_path, alt_text?
get_categories()
블로그의 카테고리 목록 조회. write_post의 category 파라미터에 사용.
(no params)
save_draft()
글을 임시저장. 바로 발행하지 않고 초안으로 저장 후 수동 발행 가능.
title, content, tags[]
활용 예시:
food-trend-automation에서 velocity burst 감지 → Claude가 블로그 초안 자동 생성 → write_post() 호출 → 네이버 블로그 자동 발행까지 완전 자동화 가능
개발 순서 (AI와 함께 · 약 1~2일)
1
환경 세팅
Python 3.11+, uv, Playwright, mcp SDK 설치. 프로젝트 스캐폴딩 생성.
Claude가 작성 약 10분
2
네이버 로그인 + 세션 저장
Playwright로 naver.com 로그인 → 쿠키를 JSON 파일에 저장. 이후 재사용.
사용자 최초 1회 로그인 코드: Claude 작성
3
write_post() 핵심 기능 구현
블로그 에디터 URL 접근 → 제목/본문 입력 → 태그 추가 → 발행 버튼 클릭. DOM 셀렉터 파악이 핵심.
Claude가 작성 + 디버깅 약 2~4시간
4
MCP 서버로 래핑
fastmcp 또는 mcp Python SDK로 Tool 등록. Claude가 호출할 수 있는 MCP 서버 완성.
Claude가 작성 약 1~2시간
5
Cowork에 플러그인 등록
claude_desktop_config.json (또는 Cowork 플러그인 설정)에 MCP 서버 경로 추가 → Claude에서 바로 호출 가능.
사용자 설정 파일 수정 가이드: Claude 제공
6
테스트 + 임시저장 검증
save_draft()로 먼저 임시저장 → 블로그에서 확인 → 정상이면 발행. get_posts()로 결과 조회.
사용자 검증 약 30분
핵심 코드 구조 미리보기
# naver_blog_mcp/server.py from mcp.server.fastmcp import FastMCP from playwright.async_api import async_playwright import json, os mcp = FastMCP("naver-blog") SESSION_FILE = os.path.expanduser("~/.naver_session.json") @mcp.tool() async def write_post( title: str, content: str, tags: list[str] = [], category: str = "", publish: bool = True ) -> str: """네이버 블로그에 새 글을 작성하고 발행합니다.""" async with async_playwright() as p: browser = await p.chromium.launch(headless=True) ctx = await browser.new_context() # 저장된 세션 쿠키 로드 await ctx.add_cookies(json.load(open(SESSION_FILE))) page = await ctx.new_page() await page.goto("https://blog.naver.com/applesodda/postwrite") # 제목 입력 await page.fill('[placeholder="제목"]', title) # 본문 입력 (스마트에디터 iframe) await page.frame_locator("#mainFrame").locator(".se-content").fill(content) # 태그 추가 for tag in tags: await page.fill('[placeholder="태그 입력"]', tag) await page.keyboard.press("Enter") # 발행 또는 임시저장 btn = "발행" if publish else "임시저장" await page.click(f'button:has-text("{btn}")') return f"✅ '{title}' 발행 완료" @mcp.tool() async def get_posts(limit: int = 10) -> list[dict]: """블로그 최근 글 목록을 반환합니다.""" ... if __name__ == "__main__": mcp.run(transport="stdio")
