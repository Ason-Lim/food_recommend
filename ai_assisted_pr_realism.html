⚠️ AI도 해결 못 하는 것

Coupang Akamai 우회 — 코드 문제가 아니라 봇 감지 대응. 시행착오 필요.
Learning Layer의 데이터 부재 — 코드를 빨리 써도 훈련 데이터가 없으면 추천 품질이 낮음.
canonical 테이블 시딩 — 한국어 식품 도메인 지식은 사람이 검토해야 함.
결론
PR-01~13 (코어 파이프라인)은 AI와 함께하면 4~8주 안에 현실적으로 완성 가능합니다.
코드 작성 속도가 5~10배 빨라지므로, 솔로 기준 "5/10"이었던 현실성이 "8/10"으로 올라갑니다.

단, Learning Layer는 속도가 아니라 데이터 부재가 문제이므로 AI가 함께해도 지금 만들 이유가 없습니다.
그리고 Google/Naver/Coupang 수집의 운영 이슈는 실제 실행하면서 맞닥뜨려야 해결됩니다 — 이건 코드 이전의 문제입니다.
