trendguide 브랜드 심볼 컨셉 4가지 비교

현재 심볼(사과 실루엣)은 applesodda는 표현하지만 trendguide의 "안내"는 담지 못합니다. 4가지 방향을 제안합니다.

안 A

사과 + 방향 화살표

사과 꼭지가 위를 향한 화살표로 전환 — "신선함에서 트렌드로"

🍏 applesodda ↑ 방향 안내

사과 형태는 유지하되 꼭지가 화살표로 바뀌어 "트렌드 방향을 안내"를 암시. 두 의미가 자연스럽게 합쳐지지만, 화살표가 약하게 보일 수 있음.

안 B — 추천

트렌드 그래프 + 사과

상승 곡선 끝에 사과가 위치 — "트렌드의 정점을 가리킨다"

가장 직관적
🍏 applesodda 📈 트렌드 상승 ✦ 정점 안내

"트렌드가 올라가는 곡선"과 "신선한 사과"가 한눈에. 상품 큐레이션 + 트렌드 안내 블로그 성격과 정확히 일치. 그래프 라인이 쿠팡/마켓컬리 랭킹 상승도 연상시킴.

안 C

나침반 + 사과

나침반 북쪽 방향이 사과 — "트렌드를 향해 안내"

🍏 applesodda 🧭 안내·가이드

"guide"라는 단어를 가장 직접적으로 표현. 나침반이 트렌드 방향을 안내한다는 의미 명확. 단, 원형 구조라 작은 크기에서 디테일이 뭉개질 수 있음.

안 D

트렌드 화살표 + 버블

삼각 방향 마크 안에 탄산 버블 — "상승 트렌드 + sodda"

🫧 sodda 버블 ▲ 상승 방향

삼각형 = 방향/트렌드 상승, 내부 버블 = sodda의 탄산감. 기하학적이고 모던한 느낌. 사과보다 "트렌드 방향"에 더 집중한 심볼. 앱 아이콘으로도 잘 작동함.

다크 · 라이트 · 아쿠아

추천 → 안 B (트렌드 그래프 + 사과)
상승 곡선 = 트렌드 리포트 · 플랫폼 랭킹 상승, 끝점의 사과 = applesodda의 신선함. "지금 가장 많이 팔리는 상품을 안내한다"는 블로그 콘셉트와 가장 일치합니다.
